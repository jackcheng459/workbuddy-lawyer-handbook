# WorkBuddy 律师实战手册

![《WorkBuddy 律师实战手册》封面](assets/cover.png)

一本面向执业律师的 WorkBuddy 实战手册。它不追求罗列全部功能，而是围绕律师真实工作中的材料整理、案件分析、主体核查、财产保全、争点拆解、文书生成、法源核验和庭审准备，说明怎样把任务交给 Agent，以及怎样检查产物能不能使用。

## 这本手册解决什么问题

- 从聊天问答转向可验收的任务派发
- 划清可以交给 Agent 的工作与必须由律师判断的事项
- 建立安全的案件工作空间和授权边界
- 用 SGP 任务派活卡讲清目标、材料、规则和交付物
- 跑通卷宗整理、主体核查、争点拆解、分头派活、文书生成、法源核验和庭审准备
- 在任务异常时正确停止、恢复和重试
- 处理客户材料保密、外发复核和团队模板沉淀

## 建议使用顺序

第一次使用时，可直接阅读第 04 节，并使用 `exercises/` 中的 A01、A02、A03 三份材料跑通首个案件任务。

完成首跑后，再按第 05 节的 SGP 任务派活卡格式，依次练习七项案件任务。每次都要检查材料范围、文件落点、引用来源、版本状态和律师待判断事项。
